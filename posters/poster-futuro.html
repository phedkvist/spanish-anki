in the future tense — part 1 of 2:
The whole tense in one rule
infinitive + é  ás  á  emos  éis  án
The same six endings for -ar, -er and -ir verbs — no exceptions. You keep the full infinitive and just add them: hablar → hablaré. Only the ten verbs marked in orange (all in rows 1–6) swap the infinitive for a short stem first.
How to build it — keep the whole infinitive and add the ending
hablar + é → hablaré
comer + é → comeré
vivir + é → viviré
nothing is cut off · the -r of the infinitive always survives
one set for all three
+ é  ás  á  emos  éis  án
hablaré, hablarás, hablará, hablaremos, hablaréis, hablarán
ten verbs shorten first
tener → tendr- · hacer → har-
decir → dir- · salir → saldr-
marked in orange below · the endings never change: tendré, haré
